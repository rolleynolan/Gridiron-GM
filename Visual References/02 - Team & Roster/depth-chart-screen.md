# Depth Chart Screen Concept

## Role

Depth Chart is a compact, table-first management workspace. It answers who occupies each role, what the full replacement
order is, whether assignments are legal and available, and how each option is performing. The earlier on-field diagram is
discarded; its space is used for more rows, evaluation context, and season statistics.

## Full-width depth table

- A full-width, scrollable table is the authoritative editing surface for every unit and package.
- Unit controls switch among Offense, Defense, and Special Teams. Package controls select the applicable base or situational
  package without opening a separate screen.
- Position groups are clearly separated and can be expanded, collapsed, or filtered. The table shows enough rows to compare
  starters, backups, and emergency depth without excessive scrolling.
- Default columns include position, order, player, role, health, morale, scout overall, confidence, and position-relevant
  current-season statistics.
- View presets can exchange season-stat columns for contract, detailed evaluation, workload, scheme fit, or other supported
  data. Columns remain configurable, reorderable, resizable, and sortable where appropriate.
- The user changes order through explicit numbered assignments and move controls rather than imprecise dragging alone.
- Suitable cross-position emergency entries may appear at the bottom of supported groups and remain clearly labeled; an
  emergency assignment does not grant a permanent secondary position.

## Decisions and feedback

- Assignment validation identifies missing starters, duplicate or illegal assignments, unavailable players, game-day
  eligibility conflicts, and package-specific requirements before the user advances.
- Delegated depth-chart control remains visible and reversible. Staff recommendations show proposed changes and rationale
  before the user accepts or overrides them where timing permits.
- Health and morale use descriptive labels. Scout summaries and detailed ratings remain estimates with confidence and report
  dates; the screen never exposes hidden ability, potential, XP, or player DNA.
- Right-clicking a player provides the shared player/coach-style context actions without replacing the table workflow.

## Visual direction

Use the accepted compact Home, Roster, and Player Profile language: dense but readable rows, restrained spacing, thin group
separators, fixed identity/navigation shell, and several useful comparisons visible at once. The table should feel like an
OOTP/FM management surface designed specifically for football depth and packages, not a decorative lineup graphic.
