- Established `Godot/` as the active C# game location.
- Established the root blueprint, roadmap, and AI instructions as the only active project-planning documents.
- Added the Godot seed asset pack: 32 team logos, seeded league data, the included font, and its readme.
- Removed the retired Python backend startup path, HTTP client, RPC client, and backend setting from the Godot runtime.
- Added a project-level NuGet configuration so the Godot/C# project builds without the obsolete Visual Studio fallback-package path.
- Added a headless C# GameCore smoke-test mode and verified a full season, playoffs, save/load, history, and retirement flow.
- Removed the retired runtime selector and C#/Python comparison tool from the dashboard.
- Restored the dashboard's missing column-picker button.
- Moved active data, logo, and font assets under `Godot/Assets/` so they are packaged with the game.
- New franchises now load the seeded 32-team league and display team logos in the franchise picker.
- Removed the retired HTTP rendering paths for roster, depth chart, standings, results, schedule, and injury-report screens; those views now call GameCore directly.
- Began the approved visual vertical slice by binding the controlled franchise's installed pixel logo into the Dashboard header, navigation rail, standings rows, and general-manager profile tile.
- Corrected Dashboard market-table initialization so Free Agency, Active Offers, Waivers, League Transactions, and Trade Finder declare their columns before configuring them; the Dashboard now completes a headless Godot launch without runtime errors.
- Reconciled the franchise-home composition with the accepted compact reference: Standings and League News now lead the page, with General Manager, Prospects, and Team Leaders beneath them. Dashboard standings use calculated W-L-T, percentage, points-for, and points-against data; news uses the shared saved-event feed; the GM tile uses persisted attributes; and Team Leaders has clickable offense, defense, and special-teams subheaders.
- Began the Roster and Player Profile slice. The roster now defaults to a dense name/position/OVR/age/contract/health/morale table and a one-line active/practice-squad/IR/cap summary. Selecting a player routes to a full-width profile workspace with a roster breadcrumb and explicit back action instead of squeezing a report beside the table; the profile removes fabricated confidence and portrait claims and uses persisted status, morale, ratings, contract, statistics, role evaluation, and trait data.
- Added deterministic staff-facing roster evaluations based on the saved GM scouting attribute. Roster and Player Profile now show bounded overall/potential ranges and an explicit confidence level instead of leaking simulation-only true ratings; role explanations use the same evaluation projection. Corrected practice-squad and injured-reserve counts in the roster summary payload.
- Completed the first-slice Player Profile data route by adding current and archived statistics, availability and contract context, known traits, depth/readiness evaluation, recent injury history, non-numeric development direction, and player transaction history. Missing narratives and histories now explain their unavailable state instead of generating sample claims.
- Began the accepted table-first Depth Chart slice. Removed the discarded field-diagram split so the assignment table uses the full workspace, and added staff evaluation ranges, confidence, health, morale, position-relevant seasonal production, and contract context. Unavailable players remain visible in their ordered groups while starter validation and automatic substitution count only available players.
- Added clickable Offense, Defense, and Special Teams depth-chart subheaders plus live player search. Filtering reuses the saved authoritative depth ordering, preserves selection only while the selected player remains visible, and provides explicit empty results instead of blank tables.
- Replaced the Depth Chart's top-level Move Up/Move Down controls with direct same-position drag-and-drop ordering. Drops are validated by GameCore, update the authoritative depth list, autosave on success, and reject invalid targets rather than visually reordering unsupported assignments.
- Completed the bounded Depth Chart slice with persisted position-group locks. Locked groups are labeled in the table, can be toggled from the workspace, retain the GM's ordered players during Auto-Fill, and append newly eligible players without discarding the saved order.
- Started the Game Day vertical slice with an authoritative persisted playback timeline. Newly simulated games now retain ordered quarter/clock, possession, down-and-distance, field position, description, scoring flags, and running score events in GameCore; Godot result payloads expose the same events for the observer, and smoke coverage verifies final-score reconciliation plus save/load continuity.
- Added the first functional full-screen Game Day observer. Watch Game resolves through GameCore, autosaves, and replays the saved timeline through the accepted scorebar, field-position, play-log, speed, highlights, and box-score hierarchy before routing to postgame. Injury events appear in the timeline; Live Adjustments remains visibly disabled until incremental simulation can apply validated changes to future snaps.
- Replaced the compact postgame recap with a full-screen immutable result hub modeled on the accepted reference. Summary, quarter scoring, box score, recorded team comparisons, player statistics, game leaders, injuries, and the complete saved game log now share one tabbed route, and Return to Dashboard refreshes the career state without reapplying the result.
- Bound the installed hard-pixel team marks into the Game Day and postgame scorebars with nearest-neighbor filtering. Game scoring inputs and recorded player lines now honor the saved top available player in each depth-chart group, so a GM's depth order determines who actually appears in the simulated game instead of GameCore silently choosing the highest-rated roster member.
- Added the persisted incremental live-game session foundation. A watched game can now start paused without prematurely committing its result, advance one saved event at a time, survive save/load, accept validated paused depth-chart reorder requests, preserve already-played events, rebuild only the unplayed outcome from the revised lineup, and apply the final result and consequences exactly once.
- Wired Watch Game to the incremental session and enabled real live depth-chart adjustments. The observer now advances GameCore one event at a time; Live Adjustments pauses play, opens the full table-first depth chart, routes drag/drop and Set Starter through the active session, autosaves, and returns to the paused observer. Full-game simulation cannot bypass an unfinished live session.
- Added a dedicated saved-career vertical-slice smoke scenario covering Dashboard, Roster, reordered/locked Depth Chart, Game Day, midgame save/load, future-only live starter adjustment, Postgame, final save/load, and refreshed Dashboard. It verifies exact playback restoration, preserved lineup decisions, one immutable result, final-score-consistent logs, and no duplicate consequences.
- Normalized 2D runtime texture filtering to nearest-neighbor for the hard-pixel presentation and added asset-smoke validation for all 32 installed team logos. Existing logo controls, Game Day, and postgame scorebars retain explicit nearest filtering; interactive helmet/alpha/readability QA remains part of production art.
- Rebuilt Trade Block and Trade Finder as one persisted GameCore-backed market workflow. The user can shop up to eight owned players/picks, optionally request a broad return position, and receives no fabricated interest before explicit submission. Returned CPU packages are ownership-, cap-, roster-, phase-, and valuation-valid; open responses can be accepted or rejected, the whole package can be withdrawn, and completed trades or season rollover clear stale offers. Removed the dead standalone Trade Block dialog and separate Active Offers navigation surface.
- Replaced immediate player release with the accepted compact confirmation flow. Roster rows now expose a nested right-click Contract menu; Release opens a read-only GameCore preview of the player's current contract plus before/after roster, payroll, and cap-room effects. No mutation occurs until confirmation, after which the normal validated transaction path removes the player from the roster/depth chart, writes league history, autosaves, and refreshes the UI.
- Reconciled Free Agency with the accepted OOTP-style table direction. Removed the permanent right-side player/offer block, expanded the sortable market table, and added a row context menu for player details and Make Offer. Contract terms now live in a separate negotiation dialog backed by the existing cap-, roster-, phase-, and salary-validated GameCore signing path; selecting or closing a player changes nothing.
- Added the accepted Roster-style Practice Squad workspace under Team navigation. The full-width table shows real practice-squad player, contract, health, eligibility, and active-roster-slot context; signing routes to the established practice-squad market and elevation remains an explicit GameCore-validated, recorded, autosaved transaction.
- Corrected the UDFA lifecycle so undrafted prospects enter a unique free-agent market immediately when the draft completes, during Rookie Signing, rather than appearing only after training camp rollover. That phase permits only undrafted-rookie signings, enforces the supported three-year contract type alongside normal salary, guarantee, cap, roster, and ownership rules, records accepted moves, and retains an idempotent rollover fallback for older saves.
- Added the GameCore-backed UDFA Market under Scouting. The table exposes real unsigned rookies, asking salary, and invitation state; one Offer Contract action opens the shared negotiation with the required three-year UDFA contract type included. The same screen supports up to ten persisted rookie-minicamp invitations and withdrawals, while signing automatically removes a redundant invitation.
- Added the accepted Final Roster Cut-Down workspace to Training Camp. It presents the real active roster, required-cut count, contracts, health, roles, and readiness in one dense table. Player selection only previews impact; releases reuse the explicit financial confirmation, and roster finalization retains all existing focus, size, and depth validation without staff-controlled automatic cuts.
- Expanded Final Roster Cut-Down into the blueprint's proposed-batch workflow. Player checkboxes now build a read-only proposal with combined roster, payroll, cap-room, remaining-cut, and starter-depth projections; one confirmation revalidates the complete current list before committing all releases, recording each transaction, autosaving, and refreshing the roster.
- Added the dedicated Training Camp Player Focus workspace. Its searchable, position-filterable roster table presents real ratings, health, fatigue, role/readiness, and focus status; selection previews the bounded effect without mutation, while explicit application remains limited to one available player per camp, records and autosaves the decision, refreshes the camp report, and persists through save/load. The screen does not invent the still-unapproved drill catalog or first-team-rep rules.
- Added the dedicated Training Camp Position Groups workspace. Its dense comparison table derives roster count, starter need, availability, injuries, average ratings, fatigue, and staff recommendations from authoritative roster state; selecting a group is read-only, while the explicit phase-gated focus action records and autosaves, refreshes reports and depth state, persists through save/load, and cannot be repeated. The screen deliberately avoids inventing unapproved drill or rep-allocation rules.
- Added the dedicated Weekly Camp Report workspace. Its dense position-group, position-competition, and health/availability tables use the persisted camp report, recorded battle outcomes, and current roster state; report refresh is read-only with respect to assignments, autosaves the derived report, and provides a direct route to the authoritative depth chart.
- Corrected training-camp position competitions to behave as staff assessments under retained GM control. The Weekly Camp Report now owns the assessment action and records explainable leaders and challengers without exposing hidden rating arithmetic or automatically changing the saved depth chart.
- Added the opening-week readiness inbox reminder. Before the user's regular-season Week 1 game, it identifies the opponent, routes to the authoritative roster workspace, and prompts review of roster legality, availability, and saved depth order without mutating any personnel decision.
- Added contextual injury-depth advisories for legal but thin position groups. The inbox identifies units with exactly enough available starters and no reserve, routes to Depth Chart, and clearly separates the advisory from blocking roster/depth violations or automatic transactions.
- Corrected practice-squad promotion semantics. The existing move is now labeled and processed as a permanent active-roster signing, with a read-only confirmation showing contract, roster, and cap changes before GameCore replaces the practice-squad contract, records the transaction, autosaves, and refreshes the roster. Temporary elevation is not implied or silently simulated.
- Added Strength & Conditioning Coach as a required staff role for new franchises and Staff Carousel vacancy replacement. Elite coaches provide a capped one-point bonus to ordinary daily fatigue recovery, and the Staff profile now explains the real bounded scouting, development, medical, conditioning, and coordinator effects instead of claiming that all staff ratings are presentation-only.
- Fixed the first reported interactive UI issues: the top workstation header now wraps instead of clipping on narrower windows; only one Team/Finances/League/Scouting/Trade Center sidebar group remains expanded; money uses `$` rather than the invariant `¤` symbol; Franchise Home scrolls correctly and its standings tile opens the authoritative standings workspace; and depth-chart drag-and-drop supports placing a player after a target so downward moves work in both normal and live-game editing.
- Added the persisted user waiver-confirmation foundation. Submitting a claim no longer transfers the player immediately: it creates an Action Required winning opportunity, blocks time advancement, survives save/load, and requires explicit finalize or cancel. Finalization revalidates and completes the normal claim transaction; cancellation records the decline and leaves the player on waivers for another claimant or expiry. Competing-claimant priority and conditional releases remain future work.
- Reconciled the dedicated Waivers market with that confirmation workflow. Its primary action now submits rather than immediately executes a claim, pending and declined states are visible in the table, expired-but-pending decisions remain visible, and the screen directs winning opportunities to Action Required instead of bypassing confirmation.
- Added persisted conditional releases to user waiver claims. The Waivers market can attach one current roster player and previews the combined roster/cap position; submission moves neither player. Action Required names the attached release, cancellation leaves that player untouched, and finalization revalidates then commits the release and acquisition together with auditable transactions.
- Completed the persisted competing-claim queue foundation. Claims now remain submitted until the waiver period closes, resolve in deterministic worst-to-best standings order, survive reload, and visibly distinguish submitted from winning states. Cancelling a user win advances the original queue without reranking or repeating that team; the next valid CPU claimant completes its transaction, while an unclaimed player enters free agency.
- Added bounded organic CPU waiver claims. On placement, non-user and non-waiving teams may enter a claim only for a meaningful same-position upgrade that remains legal with an explicit conditional release and projected cap room; selection is deterministic and capped at four teams. Resolution uses the same persisted queue, validation, transaction, and expiry paths as user claims.
- Replaced automatic practice-squad acquisition with a bounded one-year offer flow. Eligible free agents display an asking salary based on ability, morale, and positional opportunity; under-market offers are declined without changing ownership, while accepted salaries persist on the contract and create the normal audited transaction. The practice-squad workspace retains age, capacity, cap, phase, and permanent active-roster signing rules.
- Unified practice-squad recruitment with Free Agency's existing Make Offer dialog. Eligible non-UDFA players can now choose Active Roster or Practice Squad contract type in the same negotiation, which adjusts years, guarantees, asking salary, validation, and the committed destination without adding a redundant offer action.

Draft Prep now shows a war-room view with the authoritative order, prospect board, scouting detail, and a single Start Draft action; starting uses the normal offseason transition and autosave. The live stage retains those tools while adding on-clock context and a recent-picks league wire backed by immutable recap entries.

- Added a persisted private Team Draft Board with a 100-player limit. Available prospects can be added or removed from the scouting list and manually ranked; membership and order survive save/load and remain separate from public big boards and automatic scouting estimates.

- Added position and scouting-confidence filters plus transparent team-need context to the private Team Draft Board. Filtering preserves manual rank; need and role-path labels derive from current roster counts and required starter slots, and explicitly avoid claiming hidden-rating or unsupported scheme fit.
